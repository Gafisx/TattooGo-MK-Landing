# TattooGo MK

Landing page imersiva do TattooGo MK, construída com Next.js, React Three Fiber,
GSAP e Lenis.

## Desenvolvimento

```bash
npm install
npm run dev
```

## Testes

```bash
npm run lint
npx tsc --noEmit
npm run test -- --run
npm run test:coverage
npx playwright install
npm run test:e2e
```

Veja [docs/testing/README.md](./docs/testing/README.md) para a estratégia,
inventário dos cenários, mocks e limitações de cobertura.
